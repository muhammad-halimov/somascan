# Native feel для Somascan

Приложение — **одна страница и две модалки**, поэтому всё, что относится к вкладкам, роутинга, кэша лент, чатов и сессии, сюда не относится. Нужно только то, что делает одну страницу с модалками похожей на нативное приложение. Нативные правки — в отдельных файлах под `Capacitor.isNativePlatform()`.

## Что делаем

1. **Холодный старт.** `@capacitor/splash-screen` скрывать после первого рендера; тема (светлая/тёмная) ставится до первого рендера; фон окна/WebView под системную тему — без белой вспышки.
2. **Тач-полировка (глобальный CSS).**
   - `user-select: none` вне полей ввода;
   - `-webkit-tap-highlight-color: transparent`;
   - `overscroll-behavior: none`;
   - никаких `:hover`-эффектов на тач-экране;
   - `maximum-scale=1, user-scalable=no`, а шрифты инпутов ≥ 16px — иначе iOS зумит страницу при фокусе.
3. **Безопасные зоны.** `viewport-fit=cover`, отступы через `env(safe-area-inset-*)`, `ios.contentInset: 'never'`; статус-бар красить под тему (`@capacitor/status-bar`).
4. **Модалки.**
   - Открытие/закрытие анимируется (появление снизу или fade+scale, закрытие — тоже анимацией, а не мгновенным исчезновением).
   - Аппаратная кнопка «назад» на Android (`@capacitor/app`) закрывает верхнюю модалку, а не выходит из приложения.
   - Фон под модалкой не скроллится (lock на body).
   - Высота модалки — от `100dvh` с учётом safe-area и клавиатуры (`@capacitor/keyboard`), поле ввода не уходит под клавиатуру.
   - Закрытие по свайпу вниз / тапу по подложке.
5. **Отклик на действия.** Haptics (`@capacitor/haptics`) на съёмку, успешное распознавание и ошибку; состояние кнопки при нажатии; индикатор загрузки показывать, только если ждать дольше ~120 мс.
6. **Сканирование как в мессенджере.** Снимок сразу появляется на странице со статусом «распознаётся», результат подставляется на месте, а не после полноэкранного лоадера. Ошибка — «повторить» на том же элементе.
7. **Офлайн.** Снимок сохраняется локально; если нет сети, отправка на распознавание и запись в xlsx повторяются при её появлении. Баннер офлайна на странице.

## Грабли

- **iOS WKWebView:** `target="_blank"` ничего не делает — внешние ссылки открывать через `@capacitor/browser`. После тапа снимать фокус со всего, кроме полей ввода. Ширина `<input type="date">` зависит от значения — задавать явно.
- **View Transitions** (если будем делать переходы модалок): никаких `box-shadow` и фильтров на `::view-transition-old/new` — на iPhone даёт сдвиг; `window.scrollTo` откладывать до конца обновления.
- **Сеть до LM Studio / сервера на заводе:** страница открывается с origin `capacitor://localhost` (iOS) и `https://localhost` (Android) — этот origin нужно разрешить в CORS. Если WebView блокирует запрос (cookie, mixed content, http в локальной сети), слать его нативно через `CapacitorHttp`. Для http в локальной сети на Android нужен `usesCleartextTraffic` / network security config, на iOS — исключение в ATS.
- **Ключи API (Gemini / Claude):** не хранить в бандле приложения — он читается из APK/IPA. Держать на сервере-прокси или вводить в настройках и хранить в нативном хранилище.
- **Отладка iOS:** production-сборка вырезает `console` — для логов `vite build --mode development`; логи `xcrun simctl launch --console-pty <udid> com.somascan.app`, кадры `xcrun simctl io <udid> screenshot|recordVideo`.

Каждый пункт проверяем на эмуляторе (запись экрана + кадры) до выпуска сборки.
